# ADR-002: Veritabanı Motoru Olarak PostgreSQL 16+ ve Mantıksal Şema İzolasyonu

**Durum:** KABUL EDİLDİ (`ACCEPTED`)  
**Tarih:** 2026-10-30  
**Karar Vericiler:** Veri Mimarı, Çözüm Mimarı  
**İlgili Değişmezler:** K-01, K-07, K-10  

---

## 1. Bağlam
Çoklu kampüs, çoklu işletmeci (tenant/legal entity) ve yüksek finansal denetlenebilirlik gereksinimleri mevcuttur. Her modülün veri egemenliğini korurken, ilişkisel bütünlük ve gelişmiş JSON/indeksleme kabiliyetleri aranmaktadır.

## 2. Karar
1. Veritabanı motoru olarak **PostgreSQL 16+** seçilmiştir.
2. ORM olarak **Entity Framework Core 10** kullanılacaktır.
3. Her modül kendi adıyla mantıksal bir PostgreSQL şemasına (`schema: observation, passage, tariff, payments, subledger, audit`) sahip olacaktır.
4. Modüller arası çapraz SQL `JOIN` işlemleri kesinlikle yasaklanmıştır.
5. Zaman damgaları UTC `timestamptz`, para tutarları TRY kuruş cinsinden `bigint minor-unit` olarak tutulacaktır.

## 3. Sonuçlar
- **Pozitif:** Tam ACID garantisi, mantıksal şema düzeyinde rol bazlı yetkilendirme, gelecekte gerektiğinde bağımsız veritabanlarına bölünebilirlik.
- **Kısıt:** Veri tabanı migration süreçlerinin modül şemaları bazında bağımsız yönetilmesi gerekir.
