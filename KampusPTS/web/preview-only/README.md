# Kampüs PTS P00 Önizleme Arayüzü (PREVIEW_ONLY)

Bu dizin, Google AI Studio web çalışma ortamında P00 yönetişim ve mimari kütüklerini görselleştirmek için hazırlanmış hafif, salt-okunur bir React arayüzüdür.

## Önemli Sınırlar:
1. **Canlı Backend Değildir:** Bu arayüz gerçek bir ASP.NET Core veya PostgreSQL motoruna bağlı değildir.
2. **İşlevsizdir:** Kimlik doğrulama, sanal POS ödemesi, bariyer kumandası veya fatura kesme işlevi içermez.
3. **Statik Gösterim:** Yalnızca P00 kütüklerindeki (REQ, NFR, DEC, BLK, GATES) sayıları ve A1-A10 / K-01-K-12 anayasal değişmezlerini incelemek üzere tasarlanmıştır.
